Use project for canvas and map settings, and an action's options for the layer properties below. The catalogue is generated from the editor's controls and models. The same project validator checks your script.

For exact control, choose Download current map as script in Upload storyboard. It preserves native layers and cameraTracks, including custom images, split clips, groups, all keyframes, and camera movement samples. Native timing uses frames. Scene and action timing uses video timestamps or seconds.

  "name": "My full-control story", "duration": "04:00", "fps": 30,

  "scenes": [{"start": 0, "end": 240, "panel": false,
    "actions": [{"id": "army-a", "type": "object", "place": "Paris",

Groups use memberIds to refer to action IDs. Linked attacks use attackSourceId and attackTargetId. Keys support objects, group transforms, changing paths, and sunlight. All editor camera presets are available through camera.preset, with their native settings in camera.options.

For images use "image":"asset:portrait.svg", then select the file under Add supporting files. Audio clips use {"file":"voice.wav","start":0,"source":2,"duration":10,"volume":0.7,"muted":false} in a top-level audio list. An audio list replaces session audio; omit it to keep existing clips. Select the named source files before previewing. Audio bytes remain session-only, as with manual imports.
