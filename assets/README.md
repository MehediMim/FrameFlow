The landing-page images are rendered from FrameFlow's own map engine and vector unit illustrations:

- `map-documentary-preview.png`: illustrative campaign map using the documentary palette, real elevation relief, atlas labels, and field troops. Terrain attribution appears in the image; source credits are also linked from the landing-page footer via `terrain-credits.html`.
- `map-field-troops.png`: rifleman, field officer, radio operator, and field medic drawn with `map-documentary-objects.mjs`.

They are static examples. The landing-page timeline animates a separate front-line/marker demonstration and does not modify editor projects.
